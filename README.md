# mn-realty-co

Real-estate listings demo: buy, sell, agents, dashboard, login and register pages, with affordability, compare and ROI calculators. Runs on local demo data.

Live: https://mn-realty-co.vercel.app

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```
